# Proposta MANITEC DOCX v1

Template institucional estruturado para gerar DOCX server-side.

O arquivo Word binario oficial da Manitec ainda nao foi fornecido neste ciclo. Por isso, `template.json` e usado como fonte versionada e o backend gera um `.docx` final valido a partir dele. Quando o `.docx` institucional oficial existir, ele deve substituir esta definicao mantendo o mesmo schema de variaveis.
