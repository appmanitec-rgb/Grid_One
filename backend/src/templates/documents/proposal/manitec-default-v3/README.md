# Proposta comercial Manitec v3

Resumo comercial antes das condições gerais, com tabelas separadas para peças e mão de obra. Sem capa institucional. Os campos `clientProposal.*` são calculados pela apresentação pública, sem alterar preços, aprovação ou cronograma financeiro.

Pendências de prazo, vencimentos e condições comerciais ficam explícitas. O gerador não cria prazos de garantia, promete disponibilidade, escolhe dias úteis/corridos ou divide pagamentos entre empresas. Instalação só recebe uma observação quando expressamente presente no escopo, sem normas presumidas.

O v1, o v2, documentos congelados e publicações do Studio permanecem preservados. Para reconstruir o DOCX use `backend/scripts/build-proposal-template-v3.py` com python-docx.
