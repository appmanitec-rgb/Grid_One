# Proposta Manitec v2

Modelo padrão com a capa e a marca originais, paginação contínua, tabela única de itens e emissão a partir dos dados comerciais congelados na proposta.

O v1 e os arquivos aprovados permanecem preservados. Perfis já publicados no Studio mantêm sua prioridade e não são publicados novamente por este arquivo.

`!propostaitens.dataset` insere a tabela de itens com código, quantidade, unidade e desconto. Demais campos usam `{{caminho.da.variavel}}`. CNPJs e contas são dados da proposta; não devem ser digitados como constantes.
