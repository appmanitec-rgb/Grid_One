# Contrato MANITEC DOCX v1

Template institucional Word para contrato. Gera DOCX server-side sem depender da tela do ERP e segue a identidade visual da proposta MANITEC.

Arquivos:

- `template.docx`: modelo Word principal do contrato.
- `template.json`: fallback estruturado.
- `schema.json`: contrato de variaveis obrigatorias.
- `sample-data.json`: exemplo de preenchimento.

Cuidados:

- Manter placeholders como texto continuo.
- Nao incluir custos internos, margem, `hourCost`, `storageKey` ou campos administrativos.
- Homologar visualmente no Word/LibreOffice antes de usar em proposta real ao cliente.
