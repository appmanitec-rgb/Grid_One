# Laudo Tecnico MANITEC DOCX v1

Template institucional estruturado para laudo tecnico.

O modulo de laudos ja possui PDF binario, validacao publica, QR, storage privado e controle documental. A migracao completa para DOCX institucional neste fluxo proprio fica pendente porque o laudo tem versionamento, evidencias e retencao especificos que nao devem ser alterados em bloco amplo sem novo ciclo dedicado.
