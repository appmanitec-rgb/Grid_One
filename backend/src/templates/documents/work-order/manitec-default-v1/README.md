# Ordem de Servico MANITEC DOCX v1

Template institucional Word para O.S. e materiais aplicados. Gera DOCX server-side sem depender da tela do ERP e segue a identidade visual da proposta MANITEC.

Arquivos:

- `template.docx`: modelo Word principal da O.S.
- `template.json`: fallback estruturado.
- `schema.json`: contrato de variaveis obrigatorias.
- `sample-data.json`: exemplo de preenchimento.

Cuidados:

- Manter placeholders como texto continuo.
- Nao incluir custo HH, margem, custo interno, `storageKey` ou campos administrativos.
- Homologar visualmente no Word/LibreOffice antes de uso operacional definitivo.
